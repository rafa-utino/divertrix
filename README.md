# 🎮 Divertrix

> Um parque de diversões e arcade fictício inspirado na estética **Cyberpunk**, na cultura japonesa e nos espaços de entretenimento que combinam tecnologia, jogos e experiências imersivas.

---

## 📖 Sobre o projeto

**Divertrix** é um projeto de website desenvolvido como trabalho de conclusão do curso livre de **Web Design do Senac São Bernardo do Campo**.

A proposta foi criar a identidade visual e a experiência digital de um parque de diversões/arcade fictício, utilizando uma estética **cyberpunk e futurista**, com forte inspiração em elementos visuais da cultura japonesa e da tecnologia.

A ideia surgiu da minha paixão por esse universo e também da minha experiência vivendo durante **5 anos no Japão**, onde tive a oportunidade de conhecer diversos espaços de entretenimento, arcades e locais com propostas semelhantes.

O Divertrix nasceu, portanto, como uma mistura entre uma experiência pessoal e uma ideia que sempre considerei interessante: **como seria criar um espaço de entretenimento que combinasse arcade, diversão, cultura pop, tecnologia e uma estética futurista em um único lugar?**

---

## 🕹️ O conceito

O Divertrix foi imaginado como um espaço de entretenimento voltado para diferentes tipos de experiências.

Entre as atrações estão:

* 🎢 Mini montanha-russa
* 🎤 Karaokê
* 🎬 Cinema
* 🍔 Lanchonete
* 🧸 Máquinas japonesas de pegar bichinhos (UFO Catcher)
* 🕹️ Arcades e jogos
* 🎮 Outras experiências de entretenimento

O objetivo do design foi transmitir a sensação de estar entrando em um ambiente **noturno, tecnológico e imersivo**, utilizando elementos visuais associados ao cyberpunk, como neon, iluminação intensa, contrastes, interfaces futuristas e uma paleta de cores vibrantes.

---

## 🎨 Identidade visual

A identidade do Divertrix foi construída tendo como principais referências:

* 🌃 Estética Cyberpunk
* 🇯🇵 Cultura visual japonesa
* 💜 Neon e iluminação artificial
* 🤖 Tecnologia e interfaces futuristas
* 🕹️ Cultura Arcade
* 🌆 Grandes centros urbanos asiáticos
* 🎮 Cultura gamer

A combinação desses elementos busca criar uma atmosfera que remeta a uma cidade futurista durante a noite, transformando o próprio site em uma extensão da experiência que o parque pretende proporcionar.

---

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais para a construção de páginas web:

* **HTML5** — estruturação do conteúdo
* **CSS** — estilização, layout e identidade visual
* **JavaScript** — interações e comportamentos da interface



---

## 📱 Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, buscando proporcionar uma experiência consistente tanto em **computadores quanto em dispositivos móveis**.

Entre os aspectos considerados estão:

* Layout responsivo
* Adaptação de elementos para telas menores
* Navegação otimizada
* Organização do conteúdo para diferentes resoluções

---

## 🎯 Objetivos do projeto

O projeto teve como principais objetivos:

1. Aplicar na prática os conhecimentos adquiridos durante o curso de Web Design.
2. Desenvolver uma identidade visual coerente para uma marca fictícia.
3. Criar uma experiência digital baseada em um conceito visual específico.
4. Trabalhar conceitos de estruturação, layout, tipografia, cores e responsividade.
5. Transformar uma ideia pessoal em um projeto completo para portfólio.

---

## 🇯🇵 Inspiração

Uma das principais fontes de inspiração para o projeto foi minha experiência vivendo no Japão durante cinco anos.

Durante esse período, pude conhecer diferentes espaços de entretenimento e observar como arcades, máquinas de captura de pelúcias, karaokês e outras atrações fazem parte da experiência de lazer.

Essas experiências despertaram meu interesse por esse tipo de ambiente e contribuíram diretamente para a criação do conceito do Divertrix.

O projeto representa, de certa forma, uma tentativa de transformar essa inspiração em uma experiência visual própria — imaginando como seria um espaço semelhante, porém com uma identidade ainda mais voltada para o **futuro, tecnologia e estética cyberpunk**.
